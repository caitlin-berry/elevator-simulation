# Elevator Simulation | Object-Oriented System Design

**C++ | Object-Oriented Programming | Simulation | Team Collaboration**

## Overview
Developed a C++ elevator simulation game as part of a four-person team, modeling passenger transportation across a 10-floor building with three elevators. Players manage elevator movements to transport passengers efficiently while minimizing wait times and penalties.

The project demonstrates how object-oriented design and modular programming can be used to model complex, interacting systems.

## Key Features
- **Elevator Management:** Simulates the movement and operation of three elevators across ten floors.
- **Passenger Scheduling:** Processes passenger requests and tracks destinations and waiting times.
- **Time-Based Simulation:** Updates elevator positions, passenger states, and game conditions through discrete time steps.
- **Interactive Gameplay:** Allows players to control elevator movements and make decisions that affect system efficiency.
- **Performance Tracking:** Evaluates player decisions through scoring and passenger wait-time penalties.
- **Game State Management:** Supports saving and reloading simulation progress.

## Technical Highlights
- Applied object-oriented programming principles to model elevators, passengers, floors, and overall building behavior.
- Organized the simulation into modular C++ classes with distinct responsibilities.
- Implemented turn-based state updates to coordinate interacting system components.
- Used file-based input to process time-dependent passenger events.
- Integrated movement logic, passenger tracking, and scoring into a cohesive simulation.

## Team Collaboration
Completed as part of a four-person development team, with responsibilities shared across implementation and integration of system components. Collaborated to combine independently developed components into a functioning simulation.

## Skills Demonstrated
C++, object-oriented programming, class design, encapsulation, modular software architecture, simulation, state management, file I/O, debugging, and team collaboration.
